# ML-Lab-3-Non-linear-Dimensionality-Reduction---t-SNE-and-UMAP

## Notebook environment

The notebooks use the `Python (ML Lab 3)` Jupyter kernel. To create an isolated
environment and register the kernel:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m ipykernel install --user --name ml-lab-3 --display-name "Python (ML Lab 3)"
```

In VS Code, choose **Python (ML Lab 3)** from the notebook kernel picker. This
workspace's `.venv` reuses the preinstalled Python packages to avoid duplicating
large ML dependencies.
